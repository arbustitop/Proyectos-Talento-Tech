BuBus Originals: estampados DTF con presentación profesional

Tienda online creada como proyecto final del módulo Front-End JS de Talento Tech. Combina HTML semántico, Bootstrap, CSS Flexbox y JavaScript con consumo de API REST y carrito de compras persistente.

Ver tienda

De qué se trata

BuBus Originals ofrece prendas estampadas en DTF, servicios de estampado textil y soluciones de software para operarios de impresión.

Este proyecto final integra todos los conceptos del curso: diseño responsivo con Bootstrap y Flexbox, consumo de APIs con fetch(), renderizado dinámico del DOM y carrito persistido con localStorage.

Venta de productos estampados en DTF con diseños exclusivos y alta calidad de impresión.
