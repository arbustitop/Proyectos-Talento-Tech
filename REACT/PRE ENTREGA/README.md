# Pre-Entrega — React (Talento Tech)

Proyecto: **BuBus Originals** — e-commerce funcional en React (Vite + TypeScript).

## Estructura

- `proyecto-final/` — el proyecto que se entrega. Cubre los requerimientos de la pre-entrega: Layout/Header/Footer, `ItemListContainer` con `useEffect` + fetch a `productos.json`, ruteo con `react-router-dom` (`/`, `/productos`, `/producto/:id`, `/carrito`).
- `desafios/` — desafíos obligatorios de cada clase (contenido evaluado: hasta Clase 7 inclusive), incluidos como evidencia del proceso además de ya estar integrados en `proyecto-final/`:
  - `clase-05-useEffect-api/` — consumo de API externa con `useEffect`, estados de carga/error.
  - `clase-06-formularios/` — carga de archivos con feedback de carga.
  - `clase-07-router/` — rutas estáticas y dinámicas con React Router.

## Cómo correr `proyecto-final`

```
cd proyecto-final
npm install
npm run dev
```
